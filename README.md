# 141 — апелляции на разбан

Минималистичный сервис для подачи и просмотра апелляций на разбан в чате стримера. Пользователь может авторизоваться, описать ситуацию и следить за статусом заявки. Список поддерживает фильтрацию по статусу и поиск по нику.

## Возможности

- адаптивный интерфейс для компьютеров и мобильных устройств;
- процедурная анимированная сетка с реакцией на курсор;
- локальные режимы гостя и администратора;
- хранение созданных апелляций и решений в браузере;
- фильтрация по статусу и поиск по нику;
- карусель апелляций с соседними карточками и плавным переключением;
- принятие, отклонение и сброс решения в режиме администратора;
- необязательная причина отказа в заключительном вердикте;
- модальные окна с правилами и формой подачи;
- плавная прокрутка на Lenis.

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

После запуска сайт будет доступен по адресу, указанному в терминале. Точкой входа служит корневой файл `index.html`.

## Проверка сборки

```bash
npm run build
```

Готовая статическая версия появится в каталоге `docs`. GitHub Actions запускает проверку автоматически для новых коммитов и pull request.

## GitHub Pages

После отправки исходников в ветку `main` workflow `Deploy GitHub Pages` автоматически собирает и публикует сайт. В настройках репозитория откройте **Settings → Pages** и выберите **GitHub Actions** в качестве источника публикации.

Для ручной публикации выполните `npm run build` и загрузите содержимое каталога `docs`. Пути к ресурсам относительные, поэтому сайт работает внутри адреса репозитория.

## Тестовые роли

В статической версии на экране входа можно выбрать гостя или администратора. Гость просматривает и подаёт заявки. Администратор принимает, отклоняет или возвращает заявки на рассмотрение, а также может указать причину отказа.

Роль, новые заявки и решения сохраняются через `localStorage` и доступны только в браузере, где были созданы. Режим администратора предназначен для демонстрации интерфейса и не защищён серверной авторизацией.

## Серверная версия

Исходная версия с API, ChatGPT-авторизацией и Cloudflare D1 сохранена. Для её запуска используются команды `npm run dev:server` и `npm run build:server`. Она предназначена для Cloudflare Workers либо OpenAI Sites.
