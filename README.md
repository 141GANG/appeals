# 141 — апелляции на разбан

Минималистичный сервис для подачи и просмотра апелляций на разбан в чате стримера. Пользователь может авторизоваться, описать ситуацию и следить за статусом заявки. Список поддерживает фильтрацию по статусу и поиск по нику.

## Возможности

- адаптивный интерфейс для компьютеров и мобильных устройств;
- авторизация через ChatGPT в окружении OpenAI Sites;
- создание и хранение апелляций в Cloudflare D1;
- фильтрация по статусу и поиск по нику;
- модальные окна с подробностями, правилами и формой подачи;
- плавная прокрутка на Lenis.

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

После запуска сайт будет доступен по адресу, указанному в терминале. Обычно это `http://localhost:3000`.

## Проверка сборки

```bash
npm run build
```

GitHub Actions запускает эту проверку автоматически для новых коммитов и pull request.

## Данные и серверная часть

API находится в `app/api/appeals/route.ts`. Для хранения заявок используется привязка Cloudflare D1 с именем `DB`; схема и миграция находятся в каталогах `db` и `drizzle`.

Авторизация в текущей конфигурации получает данные пользователя из заголовков окружения OpenAI Sites. При переносе на другой хостинг потребуется подключить собственный способ входа.

## Публикация

GitHub можно использовать как хранилище исходного кода. Обычный GitHub Pages не поддерживает серверный API, D1 и авторизацию этого проекта. Для полной версии нужен хостинг с Cloudflare Workers и D1 либо OpenAI Sites.
